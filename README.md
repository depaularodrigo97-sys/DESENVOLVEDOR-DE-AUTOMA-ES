# Portfólio Rodrigo Vieira

Site público de portfólio profissional voltado a automações com Python, Excel, PDF, CSV, Outlook e processos administrativos e contábeis.

## Privacidade

- Nenhum documento de cliente foi incorporado.
- Nenhuma imagem, planilha, extrato, guia ou arquivo real foi utilizado.
- Os exemplos visuais são construídos apenas com HTML e CSS e usam dados fictícios.
- Apenas os contatos pessoais autorizados pelo proprietário são exibidos.

## Arquivos principais

- `index.html`
- `styles.css`
- `script.js`
